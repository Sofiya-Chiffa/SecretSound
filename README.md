## О проекте

**SecretSound** — это программа для скрытой передачи информации путем внедрения текстовых сообщений в цифровые аудиофайлы формата WAV с использованием методов стеганографии и криптографии.

Разработана в рамках курсовой работы по дисциплине "Инструментальные средства разработки программного обеспечения с открытым исходным кодом".

## Основные возможности

- **Стеганографическое встраивание** текстовых сообщений в WAV-файлы
- **Извлечение скрытых сообщений** из аудиоконтейнеров
- **Криптографическая защита** с использованием AES-256
- **Анализ емкости** аудиофайлов для оценки возможности встраивания
- **Кроссплатформенность** (Windows, Linux, macOS)

## Технологический стек

- **Язык программирования:** Python 3.8+
- **Графический интерфейс:** CustomTkinter
- **Обработка аудио:** NumPy, Wave
- **Криптография:** cryptography (AES-256)
- **Тестирование:** unittest, pytest
- **Лицензия:** MIT License

## Использование

### 1. Встраивание сообщения

1. Откройте программу и перейдите на вкладку "Кодирование"
2. Выберите исходный WAV-файл
3. Введите секретное сообщение
4. При необходимости включите шифрование AES-256 и задайте пароль
5. Укажите путь для сохранения результата
6. Нажмите "Закодировать сообщение"

### 2. Извлечение сообщения

1. Перейдите на вкладку "Декодирование"
2. Выберите аудиофайл со скрытым сообщением
3. Если сообщение зашифровано, введите пароль
4. Нажмите "Декодировать сообщение"
5. Результат появится в текстовом поле

### 3. Анализ емкости

1. Перейдите на вкладку "Анализ емкости"
2. Выберите аудиофайл для анализа
3. Нажмите "Проанализировать емкость"
4. Программа покажет технические характеристики и максимальный объем данных для встраивания

## Технические особенности

### Алгоритм LSB (Least Significant Bit)
- Замена наименее значащих битов аудиосэмплов на биты сообщения
- Минимальное влияние на качество звука
- Высокая емкость встраивания

### Шифрование AES-256
- Использование режима GCM (Galois/Counter Mode)
- Генерация ключа через PBKDF2 с 100,000 итераций
- Уникальные соль (salt) и нонс (nonce) для каждого сообщения
- Тег аутентификации для проверки целостности данных


## Тестирование

Программа включает комплексные тесты:

- **Модульные тесты** для каждого компонента
- **Интеграционные тесты** для проверки полного цикла
- **Тесты граничных случаев** (пустые строки, специальные символы)
- **Тесты обработки ошибок** (неверные пароли, поврежденные файлы)

## Производительность

- **Время обработки:** < 5 секунд для файлов до 3 минут
- **Емкость:** ~44 КБ на минуту аудио (16 бит, 44.1 кГц)
- **Качество звука:** Практически незаметные изменения (SNR > 40 дБ)
